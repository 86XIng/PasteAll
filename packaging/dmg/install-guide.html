Install PasteAll

1. Copy to Applications

Drag PasteAll onto the Applications folder in this window.

2. Allow the first launch

PasteAll is not notarized by Apple yet, so macOS blocks it the first time. Allow it once, using either option:

Option A – Terminal (recommended). Open Terminal (Applications → Utilities), paste this line, and press Return:

xattr -dr com.apple.quarantine /Applications/PasteAll.app

This only removes the “downloaded from the internet” mark from PasteAll. It prints nothing when it succeeds.

Option B – System Settings. Double-click PasteAll in Applications. When macOS says it cannot verify the app, click Done. Open System Settings → Privacy & Security, scroll down, and click Open Anyway.

3. Set up

Open PasteAll. Its icon appears in the menu bar and a short guide asks for Accessibility permission, which PasteAll needs to handle ⌘V in Finder.

Optional: in Settings → Finder Context Menu, click Turn On… to add Paste Clipboard as File to Finder’s right-click menu.

Upgrading

Quit PasteAll, drag the new version into Applications to replace the old one, repeat step 2, then click Re-authorize when PasteAll asks.

Homebrew

Alternatively, install with Homebrew, which handles step 2 for you:

brew install --cask 86xing/tap/paste-all

More information: https://github.com/86XIng/PasteAll

安装 PasteAll

1. 拷贝到“应用程序”

把本窗口中的 PasteAll 拖到 Applications（应用程序） 文件夹上。

2. 允许首次打开

PasteAll 目前还没有经过 Apple 公证，macOS 会拦截第一次打开。请任选一种方式允许一次：

方式 A：终端（推荐）。打开终端（应用程序 → 实用工具），粘贴下面这行并按下 Return：

xattr -dr com.apple.quarantine /Applications/PasteAll.app

这条命令只会移除 PasteAll 的“从互联网下载”标记，执行成功时不会有任何输出。

方式 B：系统设置。在“应用程序”中双击 PasteAll，macOS 提示无法验证时点按完成，然后打开系统设置 → 隐私与安全性，向下滚动并点按仍要打开。

3. 完成设置

打开 PasteAll，菜单栏会出现它的图标，使用指南会请求辅助功能权限——PasteAll 需要它在访达中处理 ⌘V。

可选：在设置 → 访达右键菜单中点按开启…，即可在访达右键菜单中使用将剪贴板粘贴为文件。

升级

退出 PasteAll，把新版本拖到“应用程序”中替换旧版本，重复第 2 步，然后在 PasteAll 提示时点按重新授权。

Homebrew

也可以用 Homebrew 安装，它会自动完成第 2 步：

brew install --cask 86xing/tap/paste-all

更多信息：https://github.com/86XIng/PasteAll
